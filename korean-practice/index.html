如何安裝到手機桌面？

這是 PWA 桌面安裝版，不是 Android APK；首次請透過 HTTPS 網址開啟，安裝後可在離線狀態使用練習內容。

  1. Android（Samsung／Chrome）：用 Chrome 開啟分享的 HTTPS 網址 → 按頁面上的「加入手機桌面」，或右上角 ⋮ → 安裝應用程式／加到主畫面 → 確認。
  2. iPhone：用 Safari 開啟 HTTPS 網址 → 分享 → 加入主畫面 → 視版本啟用「作為網頁 App 開啟」→ 加入。
  3. 分享給溫：最省事是直接傳安裝網址到 LINE；請溫從 LINE 選單改成 Chrome／Safari 開啟，不要只用 LINE 內建瀏覽器安裝。
  4. 離線：先在有網路時完整開啟一次，確認安裝。再開飛航模式，從主畫面圖示測試。
  5. 韓語朗讀：使用手機內建韓語語音；若沒有韓語語音包，文字、對話、翻卡、測驗仍可離線使用。
  6. 舊 ZIP／HTML：依然可以離線看，但直接從本機檔案開啟可能不支援安裝桌面 App。此 ZIP 是供獨立靜態網站部署用，不是直接點 ZIP 安裝。
  7. 資料隱私：練習內容內建於網頁。收藏保存在各自手機的瀏覽器，兩人不會互相同步；不會上傳練習答案。
注意：只有 HTTPS 或本機 localhost 環境能使用離線快取。安裝前需要一次網路下載；下載後的快取可能因清理瀏覽器資料而消失。
